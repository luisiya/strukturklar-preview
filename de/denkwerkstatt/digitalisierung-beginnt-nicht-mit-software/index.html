Digitalisierung beginnt nicht mit Software

Wenn ein Prozess nicht funktioniert, wird häufig zuerst nach einer digitalen Lösung gesucht. Eine Software kann jedoch einen schlecht strukturierten Prozess nicht automatisch verbessern.

20. Mai 2026Prozesse, Daten und Digitalisierung

01Hauptgedanke

Vor der Digitalisierung steht die Analyse:

  • Was passiert heute?
  • Welche Informationen werden benötigt?
  • Wo entstehen Fehler?
  • Welche Schnittstellen gibt es?
  • Welche Daten stehen zur Verfügung?
  • Welche Anforderungen muss eine digitale Lösung erfüllen?

02Modell

  1. Prozess→
  2. Informationen→
  3. Daten→
  4. Anforderungen→
  5. digitale Lösung→
  6. messbare Wirkung

03Ziel

Nicht einfach digitalisieren, sondern sinnvoll digitalisieren.
