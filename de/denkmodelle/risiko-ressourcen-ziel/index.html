Denkmodelle

Risiko – Ressourcen – Ziel

Entscheidungen nicht isoliert, sondern im Zusammenhang von Ziel, verfügbaren Ressourcen und Risiken betrachten.

01Ausgangsproblem

Das Modell hilft, Entscheidungen nicht isoliert zu betrachten. Eine Maßnahme kann ein Ziel erreichen, gleichzeitig aber neue Risiken oder einen hohen Ressourcenbedarf erzeugen.

02Denkfrage

Welches Ziel soll erreicht werden, welche Ressourcen stehen zur Verfügung und welche Risiken entstehen?

03Modell

  1. Ziel ↔ Ressourcen ↔ Risiken→
  2. Optionen→
  3. Wirkung

04Elemente

  1. 1

    Ziel

    • Was soll erreicht werden?
    • Welche Wirkung wird erwartet?
    • Woran wird Erfolg gemessen?
  2. 2

    Ressourcen

    • Personal
    • Zeit
    • Budget
    • Informationen
    • technische Möglichkeiten
    • vorhandene Kompetenzen
  3. 3

    Risiken

    • Fehler
    • Verzögerungen
    • Abhängigkeiten
    • fehlende Kapazitäten
    • Schnittstellenprobleme
    • Qualitätsrisiken
    • finanzielle Auswirkungen

05Beispiel

Eine Organisation möchte einen Prozess schneller machen.

  • Option A: mehr Personal
  • Option B: Prozess neu strukturieren
  • Option C: Teilautomatisierung
  • Option D: Aufgaben anders verteilen

Jede Option hat einen anderen Ressourcenbedarf, andere Risiken und eine andere erwartete Wirkung.

06Mögliche Wirkung

Entscheidungen werden vergleichbarer.

07Grenzen

Das Modell liefert eine strukturierte wirtschaftliche Entscheidungsgrundlage. Es ist keine Garantie für den tatsächlichen Eintritt einer bestimmten Wirkung.
